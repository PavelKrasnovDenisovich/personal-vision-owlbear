# Книга партии · расширение Owlbear Rodeo

Расширение открывает основной лист и боевую панель только для роли GM. HP, КД, скорость, Сл заклинаний, ячейки и использования способностей хранятся в localStorage книги ведущего; в данные токена они не записываются. Статусные эффекты отображаются игрокам на прикреплённой к токену метке. Статус «Мёртв» служит заметной меткой, что токен выбыл из игры. При переходе HP персонажа с положительного значения на 0 или ниже этот статус проставляется автоматически.

GM-only кнопка «Боевая панель» в панели инструментов Owlbear открывает боевую панель: видимые токены персонажей текущей сцены, их миниатюры, HP, переключатель урона/лечения и ползунок изменения на 1, 3, 5, 10 или 20 HP. У каждого токена можно указать результат текущей инициативы; список автоматически сортируется по убыванию. Значения инициативы хранятся локально у GM отдельно от листов персонажей. Урон сначала поглощает временные HP, лечение не поднимает выше максимума. Если у токена нет связанного листа, HP можно задать вручную в самой панели; затем ими управляют те же кнопки урона/лечения. Любой токен можно убрать из боевого списка и вернуть кнопкой «Вернуть исключённые токены»; само изображение токена на сцене не удаляется. При нуле HP на миниатюре появляется значок черепа.

Метки состояния прикреплены к токену: тёмный фон и подписи масштабируются вместе с ним, а иконки выводятся отдельными метками Owlbear, чтобы вместо символов не появлялись чёрные прямоугольники. Иконки: слепота — глаз с запретом, глухота — ухо с запретом, отравление — змея; очарование — сердце, окаменение — камень, сбит с ног — лежащий персонаж.

Листы, привязки токенов, HP, инициативы и боевые настройки отделены по Owlbear user ID: каждый GM-аккаунт ведёт собственную книгу, и новые записи остаются в ней при повторном открытии листа. Старую общую книгу можно один раз импортировать в выбранный аккаунт; отказ от импорта оставляет аккаунту отдельную пустую книгу.

На естественной 20 для атаки с броском атаки приложение автоматически удваивает количество костей в `effectFormula` и `extraDamageFormula`, не удваивая плоские бонусы. Например `1d8+5` становится `2d8+5`. Для заклинаний, где цель совершает спасбросок, критическое удвоение не применяется.

## Подготовка к запуску

1. Установить Node.js LTS.
2. В этой папке выполнить `npm install`, затем `npm run dev` для локальной разработки.
3. Для установки в Owlbear собрать `npm run build` и разместить содержимое `dist` на HTTPS-хостинге (например, GitHub Pages, Netlify или Vercel).
4. В Owlbear открыть Extensions → Add Extension и указать адрес `https://ВАШ-ДОМЕН/manifest.json`.

В `sheet.html` находится копия основного приложения, включённая в ту же публикацию, чтобы Owlbear мог открыть её из popover. Когда ты откроешь лист через токен, он сопоставится с персонажем по имени токена. Если имя отличается, появится запрос точного имени из книги. Связка токена с персонажем и сами листы хранятся только в localStorage GM на сайте. Миграция удаляет скрытые HP и ресурсы, записанные старой версией в metadata токена.

После изменения файлов снова собери приложение и загрузи именно содержимое новой папки `dist` на страницу текущего проекта Netlify. `public/_headers` добавляет CORS-заголовок, нужный Owlbear для загрузки расширения.

В лист добавлены кнопки «Перепривязать» и «Открепить» для выбранного токена. Если токен ещё не связан ни с одним персонажем, ведущий может создать карточку, выбрав JSON-файл или перетащив его в лист. Импорт поддерживает `party-book-character-v1`, а также `party-book-character` версии 1.

Для заклинаний, усиливаемых ячейкой выше базовой, укажи `upcastEffectFormula` — формулу прибавки за каждый дополнительный уровень ячейки.

В обзоре по каждой характеристике доступны отдельные проверки и спасброски. Проверка бросает d20 с модификатором характеристики; спасбросок дополнительно учитывает бонус мастерства только для отмеченного владения. Натуральные 20 и 1 выделяются в окне броска.

В боевой панели кнопка 🎲 перед инициативой бросает d20 с модификатором Ловкости связанного листа; у токена без листа используется +0, результат сразу сохраняется и пересортировывает карточки.

В листе персонажа можно загрузить GIF в библиотеку Owlbear и выбрать его для карточки. Кнопка «Представление» рассылает ссылку на GIF через Broadcast, после чего у всех подключённых участников с включённым расширением открывается небольшое окно с анимацией на 10 секунд. Окно можно закрыть раньше. Файл хранится в библиотеке Owlbear, а в книге персонажа сохраняются его имя и URL.
