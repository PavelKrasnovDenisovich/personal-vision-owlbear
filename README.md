# Личный обзор · отдельное расширение Owlbear Rodeo

Персональная экранная маска для каждого игрока. Мастер связывает токен персонажа с игроком и задаёт ему обычный радиус обзора и радиус тёмного зрения. На карте можно назначить токенам или предметам световые радиусы.

## Что умеет версия 0.2.0

- Управление доступно только мастеру через инструмент «Личный обзор · настройка».
- Один игрок может быть привязан только к одному токену; один токен — только к одному игроку.
- Режим «Ослеплён» закрывает обзор игрока чёрной маской.
- Мастер задаёт для сцены освещение «ярко» или «темно». В ярком режиме обычный радиус токена виден ясно. В темноте обычный радиус сам по себе не помогает: персонаж без тёмного зрения видит только освещённые области; персонаж с тёмным зрением видит свой радиус приглушённо.
- Световые объекты дают яркий и тусклый радиусы для игроков с активной маской.
- Позиция радиусов следует за соответствующими токенами и предметами сцены.
- У мастера есть локальный предпросмотр зрения любого привязанного игрока — второй аккаунт не нужен.
- Можно ставить почти невидимые метки света готовыми профилями: свеча, факел, фонарь и тёмное зрение с серым оттенком.
- Настройки хранятся в метаданных сцены и остаются после перезагрузки.

## Как размещать свет и зрение

В панели расширения выбери профиль и нажми «Выбрать место источника на карте». Панель закроется и включится режим размещения; щёлкни по точке на карте. Профили используют клетки сетки: свеча — 1/2, факел — 4/8, фонарь — 6/12 (яркий/внешний радиус). Профиль тёмного зрения даёт серый приглушённый круг на 12 клеток. Также можно выбрать уже размещённый предмет или токен и назначить ему свет вручную.

Радиус задаётся в клетках. В ярком режиме обычный радиус токена виден ясно. В режиме темноты обычный радиус выключается: без тёмного зрения персонаж видит только области вокруг источников; с тёмным зрением — ещё и свой заданный радиус, приглушённый примерно наполовину. Световой объект открывает яркую внутреннюю область и приглушённую внешнюю. Поставь 0, если у персонажа нет тёмного зрения.

## Установка и запуск

### GitHub Pages

В репозитории уже подготовлено автоматическое развёртывание. Используй имя репозитория `personal-vision-owlbear`, опубликуй его как public и в настройках Pages выбери источник **GitHub Actions**. Workflow соберёт `dist` и развернёт сайт после каждого push в `main`.

Адрес манифеста будет `https://ТВОЙ-ЛОГИН.github.io/personal-vision-owlbear/manifest.json`. Добавь эту ссылку в профиль Owlbear Rodeo. Включи «Личный обзор» для комнаты — после этого расширение загружается у участников этой комнаты.

В Owlbear открой сцену, войди как GM и выбери инструмент «Личный обзор · настройка». Для теста без игрока выбери токен и радиусы, затем нажми «Посмотреть текущий обзор на себе» — привязку сохранять не нужно. В предпросмотре карта принимает обычные жесты панорамирования; нажми Escape, чтобы закрыть маску и вернуть панель мастера. После подключения игроков можно открыть предпросмотр их сохранённых привязок кнопкой «Проверить на себе».

Репозиторий будет публичным: GitHub Pages на GitHub Free публикует сайт из публичного репозитория. Исходники расширения также будут видны.

### Другой статический хостинг

Для хостинга в корне домена собери проект с `PAGES_BASE_PATH=/` и размести содержимое `dist` на HTTPS-хостинге.

Игроков и токены расширение получает через APIs Owlbear. Если игрок подключён к комнате под несколькими сессиями с одной учётной записи, привязка по Owlbear user ID применится к ним всем.

## Ограничения первой версии

Маска строится кругами и не учитывает стены, углы обзора, прозрачность предметов и высоту. Световые круги доступны как источники всем привязанным игрокам, у которых активен личный обзор. Визуальная маска перекрывает карту в клиенте, но не удаляет данные сцены и не является защитой от обхода расширения. Игрок, который отключил клиентское расширение или открыл ту же сцену другим способом, может увидеть карту вне маски.

## Разработка

Требуется Node.js 18+. Команды из этой папки:

```sh
npm install
npm run dev
npm run build
```

Публичный `manifest.json` лежит в `public/`. `_headers` задаёт CORS-заголовки для хостинга Netlify.
